## Travel Tracker Frontend.

**Development:** Node 24, `npm ci`, then `npm run dev` (Vite on port 5173).

**Checks:** `npm run typecheck`, `npm test`, `npm run build`. Production files are emitted to `dist/`. See `CLAUDE.md` for architecture and browser testing.

This is the frontend application for my travel tracker project, which visualizes my trip to Japan using an interactive map. It's built with vanilla TypeScript and Vite (no UI framework) and uses the Leaflet library for mapping functionalities.

There's no point reading this README - [come check out the map directly here instead!](https://seitaro-white.github.io/travel-tracker-frontend/)
